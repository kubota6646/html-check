# HTML自動採点ツール

ブラウザ上で動作する、HTMLファイルの自動採点Webアプリです。  
サーバー不要・完全フロントエンドのみ（HTML / CSS / JavaScript バニラのみ、外部ライブラリ不使用）で実装されています。

---

## 機能一覧

- 複数のHTMLファイルを同時にアップロード（ドラッグ＆ドロップ または ファイル選択）
- ルールベースで自動採点し、**100点満点**でスコアを算出
- カテゴリ別の点数・減点理由を見やすいカード形式で表示
- **アシスト機能**: 不合格項目ごとに 💡 具体的な修正提案（追加すべきコード・変更例）を表示
- 採点結果を**CSV形式でエクスポート**（Excel対応BOM付き）

---

## 採点基準（100点満点）

| カテゴリ | 配点 | 主な確認項目 |
|---|---|---|
| ① HTML基本構造 | 30点 | `<!DOCTYPE html>` / `<html lang>` / `<head>` / `<body>` / `<meta charset>` / `<title>` |
| ② セマンティクス | 20点 | `<header>` `<main>` `<footer>` / 見出し階層 / `<img alt>` |
| ③ 可読性 | 25点 | インデント統一 / 1行120文字以内 / コメント有無 / 連続空白行 |
| ④ アクセシビリティ | 15点 | `<label>` と `<input>` の対応 / `<a>` テキスト / `lang` 属性 |
| ⑤ ベストプラクティス | 10点 | インラインスタイル不使用 / 非推奨タグ不使用 |

## 使い方

### 1. ファイルを開く

`index.html` をダブルクリックするか、ブラウザで直接開いてください。  
**サーバーは不要です。** ローカルのファイルシステムから直接開けます。

```
ダブルクリック → index.html
```

または、ブラウザのアドレスバーに以下のように入力してください。

```
file:///C:/path/to/html-check/index.html   (Windows)
file:///Users/yourname/html-check/index.html  (Mac/Linux)
```

### 2. HTMLファイルをアップロードする

- **ドラッグ＆ドロップ**：採点したいHTMLファイルをアップロードエリアにドラッグしてください。
- **ファイル選択**：「ファイルを選択」ボタンをクリックしてファイルダイアログを開いてください。

複数ファイルを同時に選択・採点できます。

### 3. 採点する

「採点する」ボタンをクリックすると、各ファイルの採点結果がカード形式で表示されます。

- 合計点数が大きく表示されます
- 各カテゴリの点数が ✅ / ⚠️ / ❌ アイコン付きで表示されます
- 「チェック項目の詳細を見る」をクリックすると、減点理由が確認できます
- ❌ の項目には **💡 アシスト** が表示され、どのコードをどこに追加・変更すればよいかを具体的に教えてくれます

### 4. CSVをエクスポートする

「📥 CSVエクスポート」ボタンをクリックすると、採点結果をCSVファイルとしてダウンロードできます。  
Excel・スプレッドシートでそのまま開けます（UTF-8 BOM付き）。

---

## アシスト機能について

不合格（❌）になったチェック項目には、青い 💡 ヒントボックスが表示されます。  
ヒントには、どのコードをどの場所に書けば良いかを具体的に示します。

**表示例：**

> 💡 `<head>` タグの直後（最初の行）に次のコードを追加してください：  
> `<meta charset="UTF-8">`

## サーバーへの展開方法

本ツールは `index.html` **1ファイル**で完結しています。  
以下のいずれかの方法でWebサーバーに配置するだけで利用できます。

### GitHub Pages を使う場合

1. このリポジトリを自分のGitHubアカウントにフォーク（または新規リポジトリにプッシュ）します。
2. リポジトリの **Settings** → **Pages** を開きます。
3. **Source** を `main` ブランチ、ルートディレクトリ（`/`）に設定して **Save** をクリックします。
4. 数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` でアクセスできます。

### Netlify / Vercel を使う場合

1. GitHubリポジトリを Netlify または Vercel と連携します。
2. ビルドコマンドは**不要**です（静的ファイルのみ）。
3. 公開ディレクトリを `/`（リポジトリルート）に設定してデプロイします。

### Webサーバー（Apache / Nginx）を使う場合

`index.html` をWebサーバーの公開ディレクトリ（例: `/var/www/html/`）にコピーするだけです。

```bash
# Apache / Nginx の例
cp index.html /var/www/html/html-check/index.html
```
